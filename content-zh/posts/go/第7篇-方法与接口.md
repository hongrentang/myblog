## 一、方法

方法是**带有接收者（receiver）的函数**。

### 定义

```go
type User struct {
    Name string
    Age  int
}

// 值接收者
func (u User) SayHello() {
    fmt.Printf("你好，我是 %s\n", u.Name)
}

// 指针接收者
func (u *User) Birthday() {
    u.Age++
}
```

### 值接收者 vs 指针接收者

```go
type Counter struct {
    value int
}

// 值接收者——不修改原值
func (c Counter) Value() int {
    return c.value
}

// 指针接收者——修改原值
func (c *Counter) Inc() {
    c.value++
}

c := Counter{value: 10}
c.Inc()
fmt.Println(c.Value())  // 11
```

**选择原则**：

| 场景 | 接收者类型 |
|------|-----------|
| 不修改原对象 | 值接收者 |
| 需要修改原对象 | 指针接收者 |
| 结构体很大（拷贝代价高） | 指针接收者 |
| 方法中需要处理 nil | 指针接收者 |

**一致性原则**：如果一个类型有指针接收者方法，通常所有方法都应该用指针接收者。

### 方法调用

```go
u := User{Name: "张三", Age: 25}
u.SayHello()           // 值调用
u.Birthday()           // Go 自动取指针 &u

p := &User{Name: "李四"}
p.SayHello()           // Go 自动解引用 (*p)
p.Birthday()
```

## 二、接口

接口定义了一组方法签名，实现了这些方法的类型自动满足该接口。

### 定义与实现

```go
// 定义接口
type Animal interface {
    Speak() string
    Move() string
}

// 实现接口（不需要显式声明 implements）
type Dog struct{}

func (d Dog) Speak() string { return "汪汪!" }
func (d Dog) Move() string  { return "跑" }

type Cat struct{}

func (c Cat) Speak() string { return "喵喵~" }
func (c Cat) Move() string  { return "走" }

// 使用接口
func MakeSound(a Animal) {
    fmt.Printf("%s 说: %s\n", a.Move(), a.Speak())
}

func main() {
    dog := Dog{}
    cat := Cat{}
    MakeSound(dog)  // 跑 说: 汪汪!
    MakeSound(cat)  // 走 说: 喵喵~
}
```

### 接口是隐式实现的

这是 Go 接口设计的核心——类型不需要声明它实现了某个接口，只要方法匹配就行。

```go
// 标准库的例子：io.Reader
type Reader interface {
    Read(p []byte) (n int, err error)
}

// os.File 实现了 Reader
// 不需要写：type File struct ... implements io.Reader
// 只要 File 有 Read 方法，就能当 Reader 用
```

### 接口值

接口在内部由两部分组成：**具体类型** + **具体值**：

```go
var a Animal   // nil 接口

a = Dog{}
// a 内部：(Dog, Dog{})

a = Cat{}
// a 内部：(Cat, Cat{})

// 接口值为 nil 的条件：类型和值都是 nil
var p *Dog = nil
a = p          // a 内部：(*Dog, nil)
fmt.Println(a == nil)  // false！因为类型不是 nil
```

### 空接口

```go
// interface{} 可以接受任何类型
var anything interface{}

anything = 42
anything = "hello"
anything = Dog{}

// 类型断言取回具体类型
n := anything.(Dog)    // 不安全，不匹配会 panic
d, ok := anything.(Dog)  // 安全
if ok {
    fmt.Println(d.Speak())
}
```

### type switch

```go
func describe(v interface{}) {
    switch v.(type) {
    case int:
        fmt.Println("整数:", v)
    case string:
        fmt.Println("字符串:", v)
    case Dog:
        fmt.Println("狗:", v.(Dog).Speak())
    default:
        fmt.Printf("未知类型: %T\n", v)
    }
}
```

### 常用标准库接口

```go
// io.Reader / io.Writer
type Reader interface {
    Read(p []byte) (n int, err error)
}
type Writer interface {
    Write(p []byte) (n int, err error)
}

// error
type error interface {
    Error() string
}

// Stringer（控制打印格式）
type Stringer interface {
    String() string
}
```

### 实现 Stringer

```go
type User struct {
    Name string
    Age  int
}

func (u User) String() string {
    return fmt.Sprintf("User(%s, %d)", u.Name, u.Age)
}

u := User{"张三", 25}
fmt.Println(u)  // User(张三, 25)
```

## 三、类型断言

```go
var v interface{} = "hello"

// 直接断言（不推荐，panic 风险）
s := v.(string)

// 安全断言（推荐）
s, ok := v.(string)
if ok {
    fmt.Println(s)
} else {
    fmt.Println("不是字符串")
}

// 断言到接口
var r io.Reader = os.Stdin
if f, ok := r.(*os.File); ok {
    fmt.Println(f.Name())  // 获取文件名
}
```

## 四、接口嵌套

接口可以通过嵌套组合成更大的接口：

```go
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Writer interface {
    Write(p []byte) (n int, err error)
}

type Closer interface {
    Close() error
}

// 组合接口
type ReadWriter interface {
    Reader
    Writer
}

type ReadWriteCloser interface {
    Reader
    Writer
    Closer
}
```

标准库中 `io.ReadWriter`、`io.ReadWriteCloser` 都是这样组合的。

## 五、接口设计原则

### 小接口原则

```go
// ✅ Go 的哲学：小接口
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Writer interface {
    Write(p []byte) (n int, err error)
}

// ❌ 大接口不推荐
type LargeInterface interface {
    Read(p []byte) (n int, err error)
    Write(p []byte) (n int, err error)
    Close() error
    Flush() error
    Seek(offset int64, whence int) (int64, error)
}
```

### 接受接口，返回结构体

```go
// 函数参数用接口，返回值用具体类型
func Process(r io.Reader) (*Result, error) {
    data, err := io.ReadAll(r)
    if err != nil {
        return nil, err
    }
    return &Result{Data: data}, nil
}
```

### 检查接口实现

有时需要静态确保一个类型实现了某个接口：

```go
// 编译时检查：如果 *File 没有实现 io.ReadWriter，编译失败
var _ io.ReadWriter = (*os.File)(nil)
```

## 六、接口性能

```go
// 接口调用有微小开销（动态分发）
// 热点路径上可考虑避免接口

// Benchmark
func BenchmarkDirect(b *testing.B) {
    d := Dog{}
    for i := 0; i < b.N; i++ {
        d.Speak()
    }
}

func BenchmarkInterface(b *testing.B) {
    var a Animal = Dog{}
    for i := 0; i < b.N; i++ {
        a.Speak()
    }
}
// 接口调用大约慢 5-15%，在大多数场景可忽略
```

## 小结

方法是带接收者的函数；接口是方法签名的集合，是 Go 实现多态的方式。Go 的接口是隐式实现的，松耦合且灵活。**小接口原则**是 Go 接口设计的核心思想。
