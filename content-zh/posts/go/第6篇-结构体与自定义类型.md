## 一、结构体

Go 没有"类"的概念，用结构体（struct）来组织数据。

### 定义与声明

```go
// 定义
type User struct {
    ID       int
    Name     string
    Email    string
    Age      int
    CreatedAt time.Time
}

// 声明方式1：字面量
u := User{
    ID:    1,
    Name:  "张三",
    Email: "zhangsan@example.com",
    Age:   25,
}

// 声明方式2：按顺序（不推荐，字段顺序变了就错）
u := User{1, "张三", "zhangsan@example.com", 25}

// 声明方式3：零值 + 逐个赋值
var u User
u.ID = 1
u.Name = "张三"
```

### 嵌套结构体

```go
type Address struct {
    Province string
    City     string
    Detail   string
}

type User struct {
    ID      int
    Name    string
    Address Address  // 嵌套
}

// 初始化
u := User{
    ID:   1,
    Name: "张三",
    Address: Address{
        Province: "广东",
        City:     "深圳",
        Detail:   "南山区",
    },
}

// 访问嵌套字段
fmt.Println(u.Address.City)
```

### 匿名结构体

```go
// 临时使用的结构体，不需要定义类型
u := struct {
    Name string
    Age  int
}{
    Name: "张三",
    Age:  25,
}

// 匿名嵌套
type User struct {
    ID   int
    Name string
    Address struct {  // 匿名嵌字段
        Province string
        City     string
    }
}
```

### 结构体是值类型

```go
u1 := User{Name: "张三"}
u2 := u1           // 拷贝整个结构体
u2.Name = "李四"
fmt.Println(u1.Name)  // "张三"（未改变）

// 需要用指针来修改
u3 := &User{Name: "张三"}
u4 := u3
u4.Name = "李四"
fmt.Println(u3.Name)  // "李四"
```

## 二、结构体 Tag

Tag 是结构体字段的元信息，常用于 JSON 序列化/ORM 映射：

```go
type User struct {
    ID        int       `json:"id"`
    Name      string    `json:"name,omitempty"`  // 为空时不序列化
    Email     string    `json:"email"`
    Password  string    `json:"-"`               // 忽略此字段
    CreatedAt time.Time `json:"created_at"`
}

u := User{
    ID:    1,
    Name:  "张三",
    Email: "test@test.com",
}

data, _ := json.Marshal(u)
fmt.Println(string(data))
// {"id":1,"name":"张三","email":"test@test.com","created_at":"0001-01-01T00:00:00Z"}
```

### 常用 Tag 格式

```go
// JSON
`json:"field_name,omitempty"`
`json:"-"`

// 数据库 ORM (GORM)
`gorm:"column:user_name;type:varchar(100);not null"`

// 表单验证 (validator)
`validate:"required,min=3,max=50"`

// YAML
`yaml:"field_name"`

// XML
`xml:"field_name,attr"`
```

## 三、自定义类型

### type 定义

```go
// 基于已有类型定义新类型
type MyInt int
type UserList []User
type Handler func(string) error

var age MyInt = 25
fmt.Printf("%T\n", age)  // main.MyInt

// 不同即使底层相同也不能隐式转换
var a MyInt = 10
var b int = 20
// a = b  // ❌ 编译错误
a = MyInt(b)  // ✅ 显式转换
```

### 自定义类型的用途

```go
// 为类型添加方法
type Counter int

func (c *Counter) Inc() {
    *c++
}

func (c *Counter) Value() int {
    return int(*c)
}

// 为切片添加方法
type Queue []int

func (q *Queue) Push(v int) {
    *q = append(*q, v)
}

func (q *Queue) Pop() (int, bool) {
    if len(*q) == 0 {
        return 0, false
    }
    v := (*q)[0]
    *q = (*q)[1:]
    return v, true
}
```

## 四、工厂函数

Go 没有构造函数，用工厂函数替代：

```go
type User struct {
    id   int    // 小写私有
    name string
}

// 工厂函数
func NewUser(name string) *User {
    return &User{
        id:   generateID(),
        name: name,
    }
}

// 带选项的工厂函数
func NewUserWithOpts(name, email string, age int) *User {
    u := &User{
        id:    generateID(),
        name:  name,
        email: email,
        age:   age,
    }
    u.validate()
    return u
}
```

## 五、结构体比较

```go
type Point struct {
    X, Y int
}

// 可比较
p1 := Point{1, 2}
p2 := Point{1, 2}
p3 := Point{3, 4}
fmt.Println(p1 == p2)  // true
fmt.Println(p1 == p3)  // false
```

如果结构体包含不可比较字段（slice、map、func），就不能直接比较：

```go
type Bad struct {
    Data []int  // slice 不能比较
}
// b1 == b2  // 编译错误

// 可以用 reflect.DeepEqual
b1 := Bad{Data: []int{1, 2}}
b2 := Bad{Data: []int{1, 2}}
fmt.Println(reflect.DeepEqual(b1, b2))  // true
```

## 六、空结构体

空结构体不占用内存，常用于信号传递：

```go
// 空结构体占用 0 字节
empty := struct{}{}

// 用 map 实现 set
type Set struct {
    m map[string]struct{}
}

func (s *Set) Add(key string) {
    s.m[key] = struct{}{}
}

func (s *Set) Has(key string) bool {
    _, ok := s.m[key]
    return ok
}

// channel 信号
ch := make(chan struct{})
go func() {
    // do something
    ch <- struct{}{}
}()
<-ch  // 等待完成
```

## 七、结构体内存对齐

Go 编译器会在结构体字段之间插入填充字节来对齐内存：

```go
// 先大字段再小字段（更紧凑）
type WellAligned struct {
    A int64    // 8 字节
    B float64  // 8 字节
    C int32    // 4 字节
    D int16    // 2 字节
    E bool     // 1 字节
}
// 共 24 字节（8+8+4+2+1+1padding）

// 乱序排列（浪费空间）
type BadAligned struct {
    A bool     // 1 字节 + 7 padding
    B int64    // 8 字节
    C bool     // 1 字节 + 3 padding
    D int32    // 4 字节
    E bool     // 1 字节 + 7 padding
}
// 共 32 字节

// 可以使用 unsafe.Sizeof 查看
fmt.Println(unsafe.Sizeof(WellAligned{}))  // 24
fmt.Println(unsafe.Sizeof(BadAligned{}))   // 32
```

## 小结

结构体是 Go 组织和封装数据的主要方式。配合 Tag 实现序列化、工厂函数替代构造函数、空结构体节省内存、内存对齐提升性能，这些都是 Go 开发中的进阶技巧。
