## 一、文件读写

### 读取整个文件

```go
// ioutil.ReadFile（Go 1.16 前）
// data, err := ioutil.ReadFile("file.txt")

// os.ReadFile（Go 1.16+ 推荐）
data, err := os.ReadFile("file.txt")
if err != nil {
    log.Fatal(err)
}
fmt.Println(string(data))
```

### 逐行读取

```go
func readLines(path string) ([]string, error) {
    file, err := os.Open(path)
    if err != nil {
        return nil, err
    }
    defer file.Close()

    var lines []string
    scanner := bufio.NewScanner(file)
    for scanner.Scan() {
        lines = append(lines, scanner.Text())
    }
    return lines, scanner.Err()
}
```

### 写入文件

```go
// 写入（覆盖）
err := os.WriteFile("output.txt", []byte("Hello, Go!"), 0644)

// 追加写入
func appendToFile(path, text string) error {
    f, err := os.OpenFile(path, os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0644)
    if err != nil {
        return err
    }
    defer f.Close()

    _, err = f.WriteString(text + "\n")
    return err
}

// 缓冲写入
f, _ := os.Create("output.txt")
defer f.Close()

w := bufio.NewWriter(f)
w.WriteString("第一行\n")
w.WriteString("第二行\n")
w.Flush()  // 将缓冲区的内容写到底层 writer
```

## 二、Reader 和 Writer 接口

### io.Reader

```go
type Reader interface {
    Read(p []byte) (n int, err error)
}
```

### io.Writer

```go
type Writer interface {
    Write(p []byte) (n int, err error)
}
```

### 标准输入输出

```go
// os.Stdin 实现了 Reader
// os.Stdout 和 os.Stderr 实现了 Writer

var buf bytes.Buffer
io.Copy(&buf, os.Stdin)  // 从 stdin 读，写入 buf
io.Copy(os.Stdout, &buf) // 从 buf 读，写入 stdout
```

### io.Copy

```go
// 复制数据，不分配大 buffer
func copyFile(src, dst string) error {
    sourceFile, err := os.Open(src)
    if err != nil {
        return err
    }
    defer sourceFile.Close()

    destFile, err := os.Create(dst)
    if err != nil {
        return err
    }
    defer destFile.Close()

    _, err = io.Copy(destFile, sourceFile)
    return err
}
```

### 链式操作

```go
// 读取压缩的 JSON 文件
file, _ := os.Open("data.json.gz")
defer file.Close()

gzReader, _ := gzip.NewReader(file)
defer gzReader.Close()

var data map[string]interface{}
json.NewDecoder(gzReader).Decode(&data)
// 数据流：file → gzip.Reader → json.Decoder → map
```

## 三、bufio 包

```go
// bufio.Reader——缓冲读取
f, _ := os.Open("large.txt")
defer f.Close()

r := bufio.NewReader(f)
for {
    line, err := r.ReadString('\n')
    if err == io.EOF {
        break
    }
    fmt.Print(line)
}

// bufio.Scanner——更方便的行读取
scanner := bufio.NewScanner(f)
for scanner.Scan() {
    line := scanner.Text()
    // 处理 line
}

// bufio.Writer——缓冲写入
var buf bytes.Buffer
w := bufio.NewWriter(&buf)
w.WriteString("hello")
w.Flush()
```

## 四、bytes 和 strings 包

### bytes.Buffer

```go
var buf bytes.Buffer

// 像文件一样使用
buf.WriteString("hello ")
buf.WriteString("world")
fmt.Println(buf.String())  // "hello world"

// Reset 重用
buf.Reset()
```

### strings

```go
s := "hello, world"

// 判断
strings.Contains(s, "hello")          // true
strings.HasPrefix(s, "hello")         // true
strings.HasSuffix(s, "world")         // true

// 分割和连接
parts := strings.Split(s, ", ")       // ["hello", "world"]
joined := strings.Join(parts, "-")    // "hello-world"

// 替换
strings.Replace(s, "world", "Go", 1)  // "hello, Go"
strings.ReplaceAll(s, "l", "L")       // "heLLo, worLd"

// 修剪
strings.TrimSpace("  hello  ")        // "hello"
strings.Trim(s, "hdl")                // "ello, wor"

// Builder（高效字符串拼接）
var b strings.Builder
b.Grow(100)  // 预分配
for i := 0; i < 1000; i++ {
    b.WriteString("a")
}
s := b.String()
```

## 五、os 包常用操作

```go
// 文件信息
info, _ := os.Stat("file.txt")
info.Name()       // 文件名
info.Size()       // 文件大小
info.IsDir()      // 是否是目录
info.ModTime()    // 修改时间
info.Mode()       // 权限

// 目录操作
os.Mkdir("dir", 0755)           // 创建单层目录
os.MkdirAll("a/b/c", 0755)      // 创建多层目录
os.Remove("file.txt")           // 删除文件
os.RemoveAll("dir")             // 删除目录及内容

// 重命名/移动
os.Rename("old.txt", "new.txt")

// 临时文件
f, _ := os.CreateTemp("", "example-*.txt")
fmt.Println(f.Name())
os.Remove(f.Name())

// 环境变量
os.Getenv("HOME")           // 获取
os.Setenv("MY_VAR", "val")  // 设置
os.LookupEnv("MY_VAR")      // 安全获取（带存在判断）
os.Environ()                // 所有环境变量

// 工作目录
dir, _ := os.Getwd()
os.Chdir("/tmp")

// 退出
os.Exit(1)     // 立即退出
os.Exit(0)     // 正常退出
```

## 六、path/filepath

```go
import "path/filepath"

// 路径操作
path := filepath.Join("dir", "sub", "file.txt")  // "dir/sub/file.txt"
dir := filepath.Dir(path)        // "dir/sub"
base := filepath.Base(path)      // "file.txt"
ext := filepath.Ext(path)        // ".txt"

// 遍历目录
filepath.WalkDir("root", func(path string, d fs.DirEntry, err error) error {
    if err != nil {
        return err
    }
    fmt.Println(path, d.IsDir())
    return nil
})

// 模式匹配
matched, _ := filepath.Match("*.txt", "file.txt")  // true
```

## 七、日志

### log 包

```go
import "log"

// 基本用法
log.Println("这是一条日志")
log.Printf("用户 %s 登录成功", "张三")

// 致命错误
log.Fatal("无法启动服务器")    // 打印日志并 os.Exit(1)
log.Fatalf("错误: %v", err)

// 条件 panic
log.Panic("无法恢复的错误")    // 打印日志并 panic
```

### 自定义 Logger

```go
// 自定义日志格式
logger := log.New(os.Stdout, "[APP] ", log.Ldate|log.Ltime|log.Lshortfile)
logger.Println("自定义日志")

// 日志到文件
f, _ := os.OpenFile("app.log", os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0644)
logger := log.New(f, "[INFO] ", log.LstdFlags)
logger.Println("日志写入文件")
```

### 结构化日志

```go
// 简单的结构化日志
type Logger struct {
    *log.Logger
}

func (l *Logger) Info(msg string, fields ...interface{}) {
    l.Printf("[INFO] %s %v", msg, fields)
}

// 更推荐使用 zerolog / zap 等第三方日志库
```

## 八、实战：文件监控

```go
func watchFile(path string) {
    initialStat, _ := os.Stat(path)

    for {
        stat, err := os.Stat(path)
        if err != nil {
            fmt.Println("文件被删除")
            return
        }

        if stat.ModTime() != initialStat.ModTime() {
            fmt.Println("文件已修改")
            initialStat = stat
        }

        time.Sleep(1 * time.Second)
    }
}
```

## 小结

I/O 是程序与外部世界的接口。Go 的 io.Reader/Writer 接口是统一的抽象，配合 bufio、bytes、strings 和 os 包，覆盖了绝大多数文件操作场景。记住：接口简单但组合强大。
