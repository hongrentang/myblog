## 一、数组

数组是固定长度的连续内存块，长度是类型的一部分。

### 声明

```go
// 声明并初始化
var nums [5]int               // [0 0 0 0 0]
var nums = [5]int{1, 2, 3, 4, 5}
nums := [5]int{1, 2, 3, 4, 5}

// 自动计算长度
nums := [...]int{1, 2, 3, 4, 5}  // 长度为 5

// 指定索引初始化
nums := [5]int{0: 10, 3: 40}      // [10 0 0 40 0]
```

### 常见操作

```go
nums := [3]int{10, 20, 30}

// 访问
fmt.Println(nums[0])   // 10
nums[1] = 25

// 长度
fmt.Println(len(nums)) // 3

// 遍历
for i, v := range nums {
    fmt.Println(i, v)
}

// 比较（数组可以直接比较）
a := [3]int{1, 2, 3}
b := [3]int{1, 2, 3}
fmt.Println(a == b)  // true
```

### 注意

```go
// 数组是值类型！赋值和传参会拷贝整个数组
func modify(arr [3]int) {
    arr[0] = 100
}

func main() {
    nums := [3]int{1, 2, 3}
    modify(nums)
    fmt.Println(nums[0])  // 1（未被修改！）
}
```

## 二、切片（Slice）

切片是 Go 最常用的数据结构，是数组的动态视图。

### 创建

```go
// 字面量
s := []int{1, 2, 3}

// make
s := make([]int, 3)      // [0 0 0]，长度=容量=3
s := make([]int, 3, 5)   // 长度 3，容量 5

// 从数组切片
arr := [5]int{1, 2, 3, 4, 5}
s1 := arr[1:4]            // [2 3 4]
s2 := arr[:3]             // [1 2 3]
s3 := arr[2:]             // [3 4 5]
s4 := arr[:]              // [1 2 3 4 5]

// nil 切片（零值）
var s []int               // nil，len=0，cap=0
```

### 切片内部结构

```
切片 = 指针 + 长度 + 容量
┌──────────┬──────────┬──────────┐
│  ptr     │  len     │  cap     │
│ (data)   │ (3)      │ (5)      │
└────┬─────┴──────────┴──────────┘
     ↓
  ┌─┬─┬─┬─┬─┐
  │1│2│3│4│5│  ← 底层数组
  └─┴─┴─┴─┴─┘
```

### 常用操作

```go
s := []int{1, 2, 3, 4, 5}

// append
s = append(s, 6)           // [1 2 3 4 5 6]
s = append(s, 7, 8, 9)     // [1 2 3 4 5 6 7 8 9]
s = append(s, []int{10, 11}...)  // 展开追加

// copy
dst := make([]int, 3)
copied := copy(dst, s)     // 返回实际复制的元素数

// 长度和容量
len(s)  // 元素个数
cap(s)  // 底层数组长度

// 子切片
sub := s[1:4]               // 新切片，共享底层数组
```

### append 扩容机制

```go
s := make([]int, 0, 2)
fmt.Println(cap(s))  // 2

s = append(s, 1)
s = append(s, 2)
fmt.Println(cap(s))  // 2（还没满）

s = append(s, 3)     // 扩容！
fmt.Println(cap(s))  // 4（容量翻倍）

// 扩容策略：
// 容量 < 1024：翻倍
// 容量 >= 1024：增加约 25%
```

### 切片陷阱

```go
// 陷阱1：切片共享底层数组
s1 := []int{1, 2, 3, 4, 5}
s2 := s1[1:3]         // [2 3]
s2[0] = 200           // 修改 s2 也会影响 s1！
fmt.Println(s1[1])    // 200

// 解决方法：使用 copy
s3 := make([]int, 2)
copy(s3, s1[1:3])     // 深拷贝

// 陷阱2：append 后的意外影响
s := []int{1, 2, 3, 4, 5}
sub := s[0:2]           // [1 2]
sub = append(sub, 100)  // 修改了 s[2]！s 变成 [1 2 100 4 5]
```

### 常用切片操作

```go
// 清除切片
s = s[:0]  // 保持底层数组，重置长度

// 克隆
clone := append([]int(nil), s...)

// 删除第 i 个元素
i := 2
s = append(s[:i], s[i+1:]...)

// 删除（保持顺序，不产生新切片）
s = append(s[:i], s[i+1:]...)  // 直接操作原切片

// 插入
s = append(s, 0)
copy(s[i+1:], s[i:])
s[i] = value
```

## 三、映射（Map）

map 是键值对集合，类似于其他语言的字典/哈希表。

### 创建

```go
// 字面量
m := map[string]int{
    "a": 1,
    "b": 2,
}

// make
m := make(map[string]int)
m["a"] = 1

// 带容量
m := make(map[string]int, 100)  // 预分配，提升性能
```

### 常用操作

```go
m := make(map[string]int)

// 增删改
m["a"] = 1                    // 添加/修改
delete(m, "a")                // 删除
delete(m, "not_exists")       // 删除不存在的键，安全

// 查询
v := m["a"]                   // 不存在返回零值（0）
v, ok := m["a"]               // ok 判断键是否存在
if v, ok := m["a"]; ok {
    fmt.Println("存在:", v)
}

// 长度
len(m)

// 遍历（无序！）
for k, v := range m {
    fmt.Println(k, v)
}
```

### map 的重要特性

```go
// 1. 零值为 nil，不能直接写入
var m map[string]int
// m["a"] = 1  // panic: assignment to nil map
m = make(map[string]int)  // 必须先初始化

// 2. 读取不存在的键返回零值
fmt.Println(m["not_exists"])  // 0（安全）

// 3. map 是引用类型
m2 := m
m2["a"] = 100    // 会影响 m

// 4. map 不能直接比较
// fmt.Println(m == m2)  // 编译错误

// 5. 遍历顺序不保证
for k, v := range m {
    _ = k; _ = v
}
```

## 四、零值与 nil 的区别

```go
var (
    arr [3]int    // [0 0 0] 不是 nil
    sl  []int     // nil
    m   map[int]string // nil
)
```

- `nil` 切片：长度和容量都是 0，append 会分配新底层数组
- `nil` map：不能写入数据

```go
var s []int
fmt.Println(s == nil)  // true
fmt.Println(len(s))    // 0
s = append(s, 1)       // ✅ nil 切片可以 append

var m map[string]int
m["a"] = 1             // ❌ panic: nil map 不能写
```

## 五、性能建议

```go
// 1. 预分配切片容量
// ❌
var s []int
for i := 0; i < 10000; i++ {
    s = append(s, i)  // 多次扩容
}

// ✅
s := make([]int, 0, 10000)
for i := 0; i < 10000; i++ {
    s = append(s, i)  // 零次扩容
}

// 2. 预分配 map 容量
// ❌
m := make(map[string]int)
for i := 0; i < 10000; i++ {
    m[fmt.Sprintf("key%d", i)] = i
}

// ✅
m := make(map[string]int, 10000)

// 3. 小数组用值传递，大结构用指针
// 如果切片很大，用指针避免拷贝
func process(data *[]int) { ... }
```

## 小结

切片和 map 是 Go 中最常用的两个数据结构。切片是数组的抽象层，灵活且高效；map 提供 O(1) 的键值查找。理解它们的底层结构和扩容机制，对写出高性能代码至关重要。
