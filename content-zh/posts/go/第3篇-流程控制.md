Go 只有 25 个关键字，流程控制相关的就是 `if`、`for`、`switch`、`defer`、`select`（并发篇讲）、`goto`。没有 `while`、`do-while`。

---

## 一、if

### 基础语法

```go
// Go 的条件不需要括号
age := 18
if age >= 18 {
    fmt.Println("成年")
}
```

### if-else

```go
if age >= 18 {
    fmt.Println("成年")
} else if age >= 12 {
    fmt.Println("少年")
} else {
    fmt.Println("儿童")
}
```

**注意**：`else` 必须和 `}` 在同一行。

### 带初始化的 if

Go 的特色——可以在 if 条件中执行一个简短语句：

```go
if score := 85; score >= 60 {
    fmt.Println("及格")
} else {
    fmt.Println("不及格")
}
// 这里不能再访问 score
```

### 用 if 判断错误

```go
// Go 标准错误处理模式
if err := doSomething(); err != nil {
    fmt.Println("出错了:", err)
    return
}

// 多返回值中的错误判断
if data, err := fetchData(); err != nil {
    log.Fatal(err)
} else {
    fmt.Println(data)
}
```

## 二、for

Go 只有 `for` 循环，没有 `while`、`do-while`。

### 完整形式

```go
for i := 0; i < 10; i++ {
    fmt.Println(i)
}
```

### "while" 形式

```go
sum := 0
for sum < 100 {
    sum += sum + 1
}
```

### "while(true)" 形式（无限循环）

```go
for {
    // 无限循环
    break  // 退出
}
```

### range 遍历

```go
// 遍历切片
nums := []int{10, 20, 30}
for index, value := range nums {
    fmt.Println(index, value)
}

// 遍历 map
m := map[string]int{"a": 1, "b": 2}
for key, value := range m {
    fmt.Println(key, value)
}

// 遍历字符串（按 rune 遍历）
for i, r := range "hello世界" {
    fmt.Printf("%d %c\n", i, r)
}

// 只取索引/键，忽略值
for i := range nums {
    fmt.Println(nums[i])
}

// 只取值，忽略索引/键
for _, v := range nums {
    fmt.Println(v)
}
```

### break 和 continue

```go
// break：跳出当前循环
for i := 0; i < 10; i++ {
    if i == 5 {
        break  // 跳出 for 循环
    }
}

// continue：跳过当前迭代
for i := 0; i < 10; i++ {
    if i%2 == 0 {
        continue  // 跳过偶数
    }
    fmt.Println(i)
}

// break 到标签（跳出外层循环）
outer:
for i := 0; i < 3; i++ {
    for j := 0; j < 3; j++ {
        if i*j > 2 {
            break outer  // 跳出两层循环
        }
        fmt.Println(i, j)
    }
}
```

## 三、switch

### 基础语法

```go
score := 85

switch {
case score >= 90:
    fmt.Println("优秀")
case score >= 80:
    fmt.Println("良好")  // 匹配到这里
case score >= 60:
    fmt.Println("及格")
default:
    fmt.Println("不及格")
}
```

### 表达式 switch

```go
switch n := 3; n {
case 1:
    fmt.Println("一")
case 2, 3, 4:  // 匹配多个值
    fmt.Println("二三四")
case 5:
    fmt.Println("五")
default:
    fmt.Println("其他")
}
```

### 不需要 break

Go 的 switch **默认不会穿透**，匹配到一个 case 后自动退出：

```go
switch n {
case 1:
    fmt.Println("1")
    // 自动 break，不会进入 case 2
case 2:
    fmt.Println("2")
}

// 如果要穿透，显式使用 fallthrough
switch n := 2; n {
case 1:
    fmt.Println("1")
    fallthrough  // 会继续执行 case 2
case 2:
    fmt.Println("2")  // case 1 fallthrough 后也会执行到这里
    fallthrough
case 3:
    fmt.Println("3")
}
// 输出：2 \n 3
```

### type switch

```go
var x interface{} = 42

switch v := x.(type) {
case int:
    fmt.Printf("整数: %d\n", v)
case string:
    fmt.Printf("字符串: %s\n", v)
case float64:
    fmt.Printf("浮点: %f\n", v)
default:
    fmt.Printf("未知类型: %T\n", v)
}
```

## 四、defer

`defer` 延迟执行，在函数返回前执行。用于资源释放、关闭文件、解锁等。

### 基本用法

```go
func readFile() error {
    f, err := os.Open("file.txt")
    if err != nil {
        return err
    }
    defer f.Close()  // 函数返回前关闭文件

    // 读文件操作
    // ...
    return nil
}
```

### defer 执行顺序（后进先出）

```go
func example() {
    defer fmt.Println("1")  // 第三个执行
    defer fmt.Println("2")  // 第二个执行
    defer fmt.Println("3")  // 第一个执行（后进先出）
}
// 输出：3 2 1
```

### defer 的参数求值时机

```go
func example() {
    x := 10
    defer fmt.Println(x)  // 输出 10（参数在 defer 声明时求值）
    x = 20
}
// 输出：10
```

### defer 修改返回值

```go
// 命名返回值时，defer 可以修改返回值
func example() (result int) {
    defer func() {
        result += 10  // 修改返回值
    }()
    return 5  // 实际返回 15
}
```

### defer 常见用途

```go
// 关闭文件
f, _ := os.Open("file.txt")
defer f.Close()

// 解锁
mu.Lock()
defer mu.Unlock()

// 记录函数执行时间
func timed() {
    defer func(start time.Time) {
        fmt.Printf("耗时: %v\n", time.Since(start))
    }(time.Now())
    // 业务逻辑...
}

// 关闭 HTTP 响应体（常犯错误）
resp, _ := http.Get(url)
defer resp.Body.Close()
```

## 五、goto

尽量少用，但偶尔有用：

```go
func example() {
    i := 0

loop:  // 标签
    fmt.Println(i)
    i++
    if i < 3 {
        goto loop  // 跳转到标签
    }
}
```

## 六、实用模式

### 函数选项模式（Fowler）

```go
type Server struct {
    Host    string
    Port    int
    Timeout time.Duration
}

type Option func(*Server)

func WithHost(host string) Option {
    return func(s *Server) {
        s.Host = host
    }
}

func WithPort(port int) Option {
    return func(s *Server) {
        s.Port = port
    }
}

func NewServer(opts ...Option) *Server {
    s := &Server{
        Host:    "localhost",
        Port:    8080,
        Timeout: 30 * time.Second,
    }
    for _, opt := range opts {
        opt(s)
    }
    return s
}

// 使用
func main() {
    s := NewServer(WithPort(9090))
    fmt.Printf("%+v\n", s)
}
```
