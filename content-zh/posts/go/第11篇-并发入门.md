## Go 的并发模型

Go 的并发基于 **CSP（Communicating Sequential Processes）** 模型：

> **不要通过共享内存来通信，而应该通过通信来共享内存。**
> — Go 并发哲学

```
传统语言：线程 ↔ 共享内存 ↔ 锁
Go 语言：  goroutine ↔ channel ↔ 消息传递
```

---

## 一、Goroutine

goroutine 是 Go 的轻量级线程，由 Go 运行时管理。

### 启动 goroutine

```go
func say(msg string) {
    for i := 0; i < 5; i++ {
        time.Sleep(100 * time.Millisecond)
        fmt.Println(msg)
    }
}

func main() {
    go say("世界")  // 在新的 goroutine 中运行
    say("你好")     // 当前 goroutine 中运行
}
```

### goroutine 的特点

```go
// 1. 轻量——栈初始只有几 KB，可动态增长
// 2. 调度由 Go Runtime 管理，没有陷入 OS 内核的高昂成本
// 3. 一个 Go 进程可以轻松创建数十万个 goroutine

// 启动方式：只需在函数调用前加 go
go func() {
    fmt.Println("在 goroutine 中运行")
}()
```

### 等待 goroutine

```go
// main 函数不会等 goroutine
func main() {
    go fmt.Println("不会打印")
}  // main 直接退出，goroutine 没机会执行

// 解决：使用 WaitGroup
func main() {
    var wg sync.WaitGroup
    wg.Add(1)
    go func() {
        defer wg.Done()
        fmt.Println("会打印")
    }()
    wg.Wait()  // 等待所有 Done
}
```

## 二、Channel

channel 是 goroutine 之间的通信管道。

### 创建和基本操作

```go
// 创建
ch := make(chan int)       // 无缓冲 channel
ch := make(chan int, 10)   // 有缓冲 channel（缓冲 10 个）

// 发送
ch <- 42

// 接收
x := <-ch
x, ok := <-ch  // ok 为 false 表示 channel 已关闭

// 关闭
close(ch)
```

### 无缓冲 channel（同步）

```go
// 无缓冲 channel 的发送和接收必须在不同的 goroutine 中同时进行
func main() {
    ch := make(chan string)

    go func() {
        fmt.Println("goroutine 准备发送...")
        ch <- "hello"  // 阻塞，直到 main 接收
        fmt.Println("goroutine 发送完成")
    }()

    time.Sleep(time.Second)  // 模拟延迟
    fmt.Println("main 准备接收...")
    msg := <-ch  // 阻塞，直到 goroutine 发送
    fmt.Println("收到:", msg)

    time.Sleep(time.Second)
}
```

### 有缓冲 channel（异步）

```go
func main() {
    ch := make(chan int, 3)

    ch <- 1  // 不阻塞
    ch <- 2  // 不阻塞
    ch <- 3  // 不阻塞
    // ch <- 4  // 阻塞！缓冲区已满

    fmt.Println(<-ch)  // 1
    fmt.Println(<-ch)  // 2
    fmt.Println(<-ch)  // 3
}
```

### 遍历 channel

```go
func main() {
    ch := make(chan int)

    go func() {
        for i := 0; i < 5; i++ {
            ch <- i
        }
        close(ch)  // 必须关闭，否则 range 会死锁
    }()

    for v := range ch {
        fmt.Println(v)
    }
}
```

### channel 的方向

```go
// 只读 channel
func reader(ch <-chan int) {
    for v := range ch {
        fmt.Println(v)
    }
}

// 只写 channel
func writer(ch chan<- int) {
    for i := 0; i < 5; i++ {
        ch <- i
    }
    close(ch)
}
```

## 三、简单示例

### 生产者-消费者

```go
func producer(ch chan<- int) {
    for i := 0; i < 10; i++ {
        fmt.Printf("生产: %d\n", i)
        ch <- i
        time.Sleep(100 * time.Millisecond)
    }
    close(ch)
}

func consumer(ch <-chan int, name string) {
    for v := range ch {
        fmt.Printf("[%s] 消费: %d\n", name, v)
        time.Sleep(150 * time.Millisecond)
    }
}

func main() {
    ch := make(chan int, 5)
    
    go producer(ch)
    go consumer(ch, "C1")
    go consumer(ch, "C2")
    
    time.Sleep(3 * time.Second)
}
```

### Worker Pool

```go
func worker(id int, jobs <-chan int, results chan<- int) {
    for job := range jobs {
        fmt.Printf("Worker %d 处理任务 %d\n", id, job)
        time.Sleep(time.Second)
        results <- job * 2
    }
}

func main() {
    jobs := make(chan int, 100)
    results := make(chan int, 100)

    // 启动 3 个 worker
    for w := 1; w <= 3; w++ {
        go worker(w, jobs, results)
    }

    // 发送 9 个任务
    for j := 1; j <= 9; j++ {
        jobs <- j
    }
    close(jobs)

    // 收集结果
    for r := 1; r <= 9; r++ {
        <-results
    }
}
```

## 四、并发与并行

```go
// 并发（Concurrency）：处理多个任务的结构
// 并行（Parallelism）：同时执行多个任务

// Go 默认使用所有 CPU 核心
fmt.Println(runtime.NumCPU())  // 查看 CPU 核心数

// 设置使用的核心数
runtime.GOMAXPROCS(4)

// GOMAXPROCS 控制同时执行用户态 Go 代码的 OS 线程数
// 默认是 CPU 核心数

// 查看当前 GOMAXPROCS
fmt.Println(runtime.GOMAXPROCS(0))

// 查看当前运行的 goroutine 数
fmt.Println(runtime.NumGoroutine())
```

## 五、常见陷阱

### 陷阱1：goroutine 泄漏

```go
// ❌ 永远不会结束
func leak() {
    ch := make(chan int)
    go func() {
        <-ch  // 永远等待
    }()
}

// ✅ 带超时
func noLeak() {
    ch := make(chan int)
    go func() {
        select {
        case <-ch:
        case <-time.After(5 * time.Second):
        }
    }()
}
```

### 陷阱2：向已关闭的 channel 发送

```go
ch := make(chan int)
close(ch)
ch <- 1  // panic: send on closed channel

// 只能由发送方关闭
// 关闭后不能再发送
// 关闭后可以继续接收（直到缓冲区为空）
```

### 陷阱3：range 未关闭的 channel

```go
ch := make(chan int)
go func() {
    for i := 0; i < 3; i++ {
        ch <- i
    }
    // 没 close
}()

for v := range ch {
    fmt.Println(v)  // 打印 0,1,2 后死锁
}
```

## 小结

goroutine 和 channel 是 Go 并发的核心。goroutine 轻量到可以创建数十万个；channel 用于 goroutine 之间的通信和同步。理解无缓冲 channel 的同步特性和有缓冲 channel 的异步特性，是掌握 Go 并发的关键。
