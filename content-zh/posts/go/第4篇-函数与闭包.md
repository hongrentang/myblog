## 一、函数定义

```go
func 函数名(参数列表) 返回值类型 {
    函数体
}
```

### 最简单的函数

```go
func sayHello() {
    fmt.Println("Hello!")
}
```

### 带参函数

```go
func greet(name string) {
    fmt.Printf("Hello, %s!\n", name)
}

// 相同类型的连续参数可以省略类型
func add(a, b int) int {
    return a + b
}
```

### 多返回值

这是 Go 的特色，替代了其他语言的异常/元组：

```go
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("除数不能为 0")
    }
    return a / b, nil
}

// 使用
result, err := divide(10, 2)
if err != nil {
    fmt.Println("错误:", err)
    return
}
fmt.Println(result)
```

### 命名返回值

```go
// 返回值可以命名，函数体中可以直接赋值
func divide(a, b float64) (result float64, err error) {
    if b == 0 {
        err = fmt.Errorf("除数不能为 0")
        return  // 等价于 return result, err
    }
    result = a / b
    return  // 裸返回
}
```

**裸返回（naked return）**在短函数中可读性不错，但在长函数中建议显式返回。

## 二、函数是一等公民

Go 中函数是值类型，可以赋值给变量、作为参数传递、作为返回值。

### 函数类型

```go
// 定义函数类型
type MathFunc func(int, int) int

// 使用
var add MathFunc = func(a, b int) int {
    return a + b
}
fmt.Println(add(1, 2))  // 3
```

### 函数作为参数

```go
func apply(nums []int, f func(int) int) []int {
    result := make([]int, len(nums))
    for i, v := range nums {
        result[i] = f(v)
    }
    return result
}

// 使用
nums := []int{1, 2, 3, 4}
double := func(x int) int { return x * 2 }
fmt.Println(apply(nums, double))  // [2 4 6 8]
```

### 函数作为返回值

```go
func multiplier(factor int) func(int) int {
    return func(x int) int {
        return x * factor
    }
}

// 使用
double := multiplier(2)
triple := multiplier(3)
fmt.Println(double(5))   // 10
fmt.Println(triple(5))   // 15
```

## 三、闭包

闭包是一个函数"记住"了它外部变量的能力：

```go
func counter() func() int {
    count := 0
    return func() int {
        count++
        return count
    }
}

c1 := counter()
fmt.Println(c1())  // 1
fmt.Println(c1())  // 2
fmt.Println(c1())  // 3

c2 := counter()    // 新的计数器
fmt.Println(c2())  // 1
```

### 闭包陷阱（常见 bug）

```go
// ❌ 常见错误：循环中捕获外部变量
funcs := []func(){}
for i := 0; i < 3; i++ {
    funcs = append(funcs, func() {
        fmt.Println(i)  // 捕获的是同一个 i
    })
}
for _, f := range funcs {
    f()  // 全部输出 3，因为循环结束后 i = 3
}

// ✅ 修正：通过参数传值
for i := 0; i < 3; i++ {
    i := i  // 声明一个新的 i，每个迭代都有自己的副本
    funcs = append(funcs, func() {
        fmt.Println(i)
    })
}

// 或者用闭包接收参数
for i := 0; i < 3; i++ {
    funcs = append(funcs, func(n int) func() {
        return func() { fmt.Println(n) }
    }(i))
}
```

Go 1.22+ 已经修复了 `for range` 中的闭包问题，但传统 `for i := 0; ...` 仍需要留意。

## 四、可变参数

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

fmt.Println(sum(1, 2))       // 3
fmt.Println(sum(1, 2, 3, 4)) // 10

// 展开切片
nums := []int{1, 2, 3}
fmt.Println(sum(nums...))    // 6
```

## 五、匿名函数

直接在代码中定义，不需要命名：

```go
// 定义并立即执行
func() {
    fmt.Println("立即执行")
}()

// 赋值给变量
double := func(x int) int {
    return x * 2
}
fmt.Println(double(5))
```

## 六、init 函数

每个包可以有多个 `init` 函数，在包被导入时自动执行：

```go
// 执行顺序：全局变量初始化 → init → main
var version = "1.0.0"

func init() {
    fmt.Println("init 1")
}

func init() {
    fmt.Println("init 2")
}

func main() {
    fmt.Println("main")
}
// init 先于 main 执行
```

## 七、递归

```go
func factorial(n int) int {
    if n <= 1 {
        return 1
    }
    return n * factorial(n-1)
}

// 斐波那契
func fibonacci(n int) int {
    if n <= 1 {
        return n
    }
    return fibonacci(n-1) + fibonacci(n-2)
}
```

## 八、实用模式

### 函数选项模式（Functional Options）

这在项目实战中很常见：

```go
type ServerConfig struct {
    Host    string
    Port    int
    Timeout time.Duration
}

type ServerOption func(*ServerConfig)

func WithHost(host string) ServerOption {
    return func(c *ServerConfig) {
        c.Host = host
    }
}

func WithPort(port int) ServerOption {
    return func(c *ServerConfig) {
        c.Port = port
    }
}

func NewServer(opts ...ServerOption) *ServerConfig {
    // 默认配置
    cfg := &ServerConfig{
        Host:    "localhost",
        Port:    8080,
        Timeout: 30 * time.Second,
    }
    // 应用选项
    for _, opt := range opts {
        opt(cfg)
    }
    return cfg
}

func main() {
    srv := NewServer(WithPort(9090))
}
```

### 装饰器模式

```go
func logging(next func(string) error) func(string) error {
    return func(s string) error {
        log.Printf("调用: %s", s)
        err := next(s)
        log.Printf("完成: err=%v", err)
        return err
    }
}

func handler(name string) error {
    fmt.Println("处理:", name)
    return nil
}

func main() {
    wrapped := logging(handler)
    wrapped("test")
}
```

## 九、延迟调用性能

```go
// defer 有微小的性能开销，热点路径上避免过多 defer

// ❌ 热点路径不推荐
for i := 0; i < 1000000; i++ {
    mu.Lock()
    defer mu.Unlock()  // 不必要
}

// ✅ 手动解锁
for i := 0; i < 1000000; i++ {
    mu.Lock()
    // 操作
    mu.Unlock()
}
```
