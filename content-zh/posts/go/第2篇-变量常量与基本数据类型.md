## 一、变量声明

Go 有四种变量声明方式：

### 1. var 声明

```go
var name string = "张三"
var age int = 25
```

### 2. 类型推断

```go
var name = "张三"  // 自动推断为 string
var age = 25       // 自动推断为 int
```

### 3. 批量声明

```go
var (
    name   string = "张三"
    age    int    = 25
    height        = 175.5  // float64
    active        = true    // bool
)
```

### 4. 短变量声明（推荐）

```go
name := "张三"     // 等价于 var name = "张三"
age := 25
```

短变量声明是 Go 中最常用的方式，但只能在函数内部使用。

### 变量规则

```go
// 1. 声明了必须使用，否则编译错误
// var x int  // ❌ 编译错误：x declared but not used

// 2. 多变量赋值
x, y := 1, 2
x, y = y, x  // 交换值，不需要临时变量

// 3. _ 忽略返回值
_, err := doSomething()

// 4. 零值初始化
var a int       // 0
var b string    // ""
var c bool      // false
var d float64   // 0
var e []int     // nil
```

## 二、常量

```go
// 单个常量
const Pi = 3.14159

// 批量常量
const (
    StatusOK    = 200
    StatusNotFound = 404
    StatusError    = 500
)

// 常量可以作为枚举
const (
    Monday    = 1
    Tuesday   = 2
    Wednesday = 3
)
```

### iota 枚举

```go
const (
    Monday = iota       // 0
    Tuesday             // 1
    Wednesday           // 2
    Thursday            // 3
    Friday              // 4
    Saturday            // 5
    Sunday              // 6
)

const (
    _  = iota             // 忽略 0
    KB = 1 << (10 * iota) // 1 << 10 = 1024
    MB                    // 1 << 20 = 1048576
    GB                    // 1 << 30
    TB                    // 1 << 40
)
```

常量编译时确定，不能使用运行时表达式：

```go
const x = len("hello")  // ✅ 编译期函数
const y = time.Now()    // ❌ 运行时函数，编译错误
```

## 三、基本数据类型

### 布尔型

```go
var active bool = true
var done bool   // 默认为 false

// 逻辑运算
!active         // NOT
active && done  // AND
active || done  // OR
```

### 整数类型

```go
// 有符号
var a int     // 平台相关：32位系统=32bit，64位系统=64bit
var b int8    // -128 ~ 127
var c int16   // -32768 ~ 32767
var d int32   // -2^31 ~ 2^31-1
var e int64   // -2^63 ~ 2^63-1

// 无符号
var f uint    // 同 int，但非负
var g uint8   // 0 ~ 255（byte 的别名）
var h uint16  // 0 ~ 65535
var i uint32  // 0 ~ 2^32-1
var j uint64  // 0 ~ 2^64-1

// 特殊
var k byte = 255       // uint8 的别名
var l rune = '中'      // int32 的别名，表示 Unicode 码点
```

**常用选择**：
- 整数用 `int`
- 二进制字节用 `byte`
- Unicode 字符用 `rune`

### 浮点类型

```go
var f1 float32        // 约 7 位精度
var f2 float64        // 约 15 位精度（推荐）

// 科学计数法
var f3 = 1.5e10       // 15000000000
var f4 = 1.5E-3       // 0.0015

// 特殊值
var inf = math.Inf(1)  // 正无穷
var nan = math.NaN()   // 非数字
```

**浮点数比较陷阱**：

```go
// ❌ 不要直接比较浮点数
if 0.1 + 0.2 == 0.3 {
    fmt.Println("相等")  // 不会执行！
}

// ✅ 使用误差比较
const epsilon = 1e-9
if math.Abs((0.1+0.2)-0.3) < epsilon {
    fmt.Println("近似相等")
}
```

### 字符串

```go
// 双引号字符串
var s1 = "hello"

// 反引号原始字符串（不会转义，支持换行）
var s2 = `第一行
第二行
第三行`

// 字符串拼接
s := "hello, " + "world"

// 取长度
len(s)  // 返回字节数，不是字符数

// 索引（获取字节）
s[0]    // 'h'

// 子串
s[0:5]  // "hello"

// 遍历（按字节）
for i := 0; i < len(s); i++ {
    fmt.Printf("%x ", s[i])
}

// 遍历（按 rune）
for i, r := range "hello世界" {
    fmt.Printf("%d %c\n", i, r)
}
```

### 字符串不可变

```go
s := "hello"
// s[0] = 'H'  // ❌ 编译错误

// 需要修改时转成 []byte
b := []byte(s)
b[0] = 'H'
s = string(b)  // "Hello"
```

## 四、类型转换

Go **没有**隐式类型转换，需要显式转换：

```go
var a int = 10
var b int64 = 20

// a = b          // ❌ 编译错误：类型不匹配
a = int(b)        // ✅ 显式转换

// 安全的转换范围
var x int32 = 1000
var y int8 = int8(x)  // 编译通过，但可能溢出（如果 x > 127）

// 数字转字符串
s := strconv.Itoa(100)          // "100"
n, _ := strconv.Atoi("100")     // 100

// 字符串和 []byte
s := "hello"
b := []byte(s)      // string → []byte
s2 := string(b)     // []byte → string

// 浮点转整数（截断小数）
f := 3.14
i := int(f)         // 3
```

## 五、零值

Go 变量声明后会自动初始化为零值，**没有未初始化的变量**：

```go
var i int       // 0
var f float64   // 0
var b bool      // false
var s string    // ""
var p *int      // nil
var sl []int    // nil
var m map[int]string // nil
var ch chan int // nil
```

## 六、命名规范

```go
// 驼峰命名
userName := "张三"
userAge := 25

// 包级别变量
var version = "1.0.0"

// 首字母大写 = 公有（导出）
var PublicVar = "I'm public"

// 首字母小写 = 私有（非导出）
var privateVar = "I'm private"

// 缩写保持大小写一致
var userID int           // ✅
var userId int           // ❌ 不用
var urlString string     // URL 作为整体，大写成 URLString
```
