## 一、反射

反射（reflect）让程序在运行时检查类型和值。

### reflect.Type 和 reflect.Value

```go
import "reflect"

func inspect(v interface{}) {
    t := reflect.TypeOf(v)
    fmt.Println("类型:", t.Name())
    fmt.Println("种类:", t.Kind())

    val := reflect.ValueOf(v)
    fmt.Println("值:", val)
}

inspect(42)
// 类型: int
// 种类: int

inspect("hello")
// 类型: string
// 种类: string
```

### 读取结构体字段

```go
type User struct {
    ID   int    `json:"id"`
    Name string `json:"name"`
    Age  int    `json:"age,omitempty"`
}

u := User{ID: 1, Name: "张三", Age: 25}
t := reflect.TypeOf(u)

for i := 0; i < t.NumField(); i++ {
    field := t.Field(i)
    fmt.Printf("字段: %s, 类型: %v, Tag: %s\n",
        field.Name, field.Type, field.Tag.Get("json"))
}
// 字段: ID, 类型: int, Tag: id
// 字段: Name, 类型: string, Tag: name
// 字段: Age, 类型: int, Tag: age,omitempty
```

### 修改值（通过指针）

```go
x := 42
v := reflect.ValueOf(&x)  // 必须是指针
v.Elem().SetInt(100)
fmt.Println(x)  // 100
```

### 调用方法

```go
type Calculator struct{}

func (c Calculator) Add(a, b int) int {
    return a + b
}

c := Calculator{}
v := reflect.ValueOf(c)
method := v.MethodByName("Add")
args := []reflect.Value{reflect.ValueOf(3), reflect.ValueOf(4)}
result := method.Call(args)
fmt.Println(result[0].Int())  // 7
```

### 使用场景

**1. 通用序列化/反序列化**

```go
func toMap(v interface{}) map[string]interface{} {
    result := make(map[string]interface{})
    val := reflect.ValueOf(v)

    if val.Kind() == reflect.Ptr {
        val = val.Elem()
    }

    t := val.Type()
    for i := 0; i < val.NumField(); i++ {
        field := t.Field(i)
        result[field.Name] = val.Field(i).Interface()
    }
    return result
}
```

**2. 验证器**

```go
func validate(v interface{}) error {
    val := reflect.ValueOf(v)
    if val.Kind() == reflect.Ptr {
        val = val.Elem()
    }

    t := val.Type()
    for i := 0; i < val.NumField(); i++ {
        field := t.Field(i)
        value := val.Field(i)

        // 检查 required tag
        if field.Tag.Get("validate") == "required" && value.IsZero() {
            return fmt.Errorf("字段 %s 不能为空", field.Name)
        }
    }
    return nil
}

type Request struct {
    Name  string `validate:"required"`
    Email string `validate:"required"`
}
```

## 二、泛型

Go 1.18 引入了泛型。

### 泛型函数

```go
// 普通函数——每种类型都要写
func sumInts(nums []int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

func sumFloats(nums []float64) float64 {
    total := 0.0
    for _, n := range nums {
        total += n
    }
    return total
}

// 泛型函数——一份代码解决
func sum[T int | float64](nums []T) T {
    var total T
    for _, n := range nums {
        total += n
    }
    return total
}

// 使用
fmt.Println(sum([]int{1, 2, 3}))           // 6
fmt.Println(sum([]float64{1.5, 2.5, 3})) // 7.0
```

### 泛型类型

```go
// 泛型栈
type Stack[T any] struct {
    items []T
}

func (s *Stack[T]) Push(item T) {
    s.items = append(s.items, item)
}

func (s *Stack[T]) Pop() (T, bool) {
    if len(s.items) == 0 {
        var zero T
        return zero, false
    }
    item := s.items[len(s.items)-1]
    s.items = s.items[:len(s.items)-1]
    return item, true
}

func (s *Stack[T]) Peek() (T, bool) {
    if len(s.items) == 0 {
        var zero T
        return zero, false
    }
    return s.items[len(s.items)-1], true
}

// 使用
intStack := Stack[int]{}
intStack.Push(10)
intStack.Push(20)
val, _ := intStack.Pop()
fmt.Println(val)  // 20

strStack := Stack[string]{}
strStack.Push("hello")
```

### 泛型集合

```go
// 类型安全的 Set
type Set[T comparable] struct {
    items map[T]struct{}
}

func NewSet[T comparable]() *Set[T] {
    return &Set[T]{items: make(map[T]struct{})}
}

func (s *Set[T]) Add(item T) {
    s.items[item] = struct{}{}
}

func (s *Set[T]) Remove(item T) {
    delete(s.items, item)
}

func (s *Set[T]) Has(item T) bool {
    _, ok := s.items[item]
    return ok
}

func (s *Set[T]) Items() []T {
    result := make([]T, 0, len(s.items))
    for item := range s.items {
        result = append(result, item)
    }
    return result
}
```

### 泛型约束

```go
// 定义约束接口
type Number interface {
    int | int64 | float64
}

// 使用约束
func sum[T Number](nums []T) T {
    var total T
    for _, n := range nums {
        total += n
    }
    return total
}

// 约束中的 ~ 表示底层类型
type MyInt int

// 只接受 int
// func add[T int](a, b T) T { return a + b }
// MyInt 不能用于这个函数

// 接受底层类型为 int 的所有类型
func add[T ~int](a, b T) T { return a + b }
// MyInt 也可以使用

// 常见约束
// any = interface{}
// comparable = 可比较的 (== 和 !=)
// Ordered = 可排序的 (golang.org/x/exp/constraints)
```

### 泛型方法（限制）

```go
// 注意：泛型方法不能有额外的类型参数
type Container struct{}

// ❌ 方法不能有额外的泛型参数
// func (c Container) Transform[T any](item T) T { ... }

// ✅ 必须把泛型放在类型上
type Container2[T any] struct {
    value T
}

func (c Container2[T]) Value() T {
    return c.value
}
```

## 三、反射 vs 泛型

| 对比 | 反射 | 泛型 |
|------|------|------|
| 时机 | 运行时 | 编译时 |
| 性能 | 有开销 | 零开销（编译期展开）|
| 类型安全 | 不安全（需断言）| 类型安全 |
| 适用场景 | 序列化、ORM、未知类型 | 容器、算法、数据结构 |
| 代码复杂度 | 复杂 | 简洁 |

**建议**：能用泛型解决的问题就不用反射。泛型是编译时安全的，且没有运行时开销。

## 四、实用模式

### 泛型 + 接口的组合

```go
// 通用的缓存接口
type Cache[T any] interface {
    Get(key string) (T, bool)
    Set(key string, value T)
}

// 内存实现
type MemoryCache[T any] struct {
    data map[string]T
    mu   sync.RWMutex
}

func NewMemoryCache[T any]() *MemoryCache[T] {
    return &MemoryCache[T]{data: make(map[string]T)}
}

func (c *MemoryCache[T]) Get(key string) (T, bool) {
    c.mu.RLock()
    defer c.mu.RUnlock()
    v, ok := c.data[key]
    return v, ok
}

func (c *MemoryCache[T]) Set(key string, value T) {
    c.mu.Lock()
    defer c.mu.Unlock()
    c.data[key] = value
}
```

## 小结

反射让 Go 有了运行时自省能力，适合框架、ORM、序列化等场景，但有性能开销。泛型（1.18+）提供了编译时多态，类型安全且零开销，适合容器、算法和数据结构。两者各有适用场景，能用泛型解决的问题就不要用反射。
