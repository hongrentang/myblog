## 数据库操作

### 创建数据库

```sql
-- 基本创建
CREATE DATABASE shop;

-- 指定字符集和排序规则
CREATE DATABASE shop
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_unicode_ci;

-- 如果不存在则创建（避免重复创建报错）
CREATE DATABASE IF NOT EXISTS shop;
```

**字符集选择建议**：始终使用 `utf8mb4`，它支持完整的 Unicode 字符（包括 emoji）。`utf8` 在 MySQL 中最多只支持 3 字节的字符。

### 查看和选择数据库

```sql
-- 查看所有数据库
SHOW DATABASES;

-- 查看当前数据库
SELECT DATABASE();

-- 切换数据库
USE shop;
```

### 修改数据库

```sql
ALTER DATABASE shop CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 删除数据库

```sql
-- ⚠️ 删除不可恢复
DROP DATABASE shop;
DROP DATABASE IF EXISTS shop;
```

## 表操作

### 命名规范

| 项目 | 建议 |
|------|------|
| 数据库名 | 小写英文单词，下划线分隔，如 `shop_order` |
| 表名 | 复数名词，如 `users`、`orders`、`products` |
| 列名 | 小写蛇形，如 `user_name`、`created_at` |
| 主键 | 统一叫 `id` |
| 外键 | 关联表名 + `_id`，如 `user_id` |

### 创建表

```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL,
    age INT DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 查看表结构
DESC users;

-- 查看建表语句
SHOW CREATE TABLE users;
```

### 完整建表示例

```sql
CREATE TABLE orders (
    id          BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    order_no    VARCHAR(32) NOT NULL COMMENT '订单号',
    user_id     INT NOT NULL COMMENT '用户ID',
    total_amount DECIMAL(10,2) NOT NULL DEFAULT 0.00 COMMENT '总金额',
    status      TINYINT NOT NULL DEFAULT 0 COMMENT '状态:0待支付1已支付2已发货3已完成',
    paid_at     DATETIME COMMENT '支付时间',
    created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_order_no (order_no),
    KEY idx_user_id (user_id),
    KEY idx_status (status),
    KEY idx_created_at (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='订单表';
```

## 修改表结构

### 添加列

```sql
ALTER TABLE users ADD COLUMN phone VARCHAR(20) AFTER email;
ALTER TABLE users ADD COLUMN address VARCHAR(200) DEFAULT '';
ALTER TABLE users ADD COLUMN gender TINYINT AFTER name;
```

`AFTER` 指定位置，如果不要 `AFTER` 则默认加到最后。

### 修改列

```sql
-- 修改列类型
ALTER TABLE users MODIFY COLUMN phone VARCHAR(30);

-- 修改列名和类型
ALTER TABLE users CHANGE COLUMN phone mobile VARCHAR(20);

-- 设置默认值
ALTER TABLE users ALTER COLUMN age SET DEFAULT 18;

-- 删除默认值
ALTER TABLE users ALTER COLUMN age DROP DEFAULT;
```

### 删除列

```sql
ALTER TABLE users DROP COLUMN address;
```

### 重命名列

```sql
ALTER TABLE users RENAME COLUMN mobile TO phone;
```

## 索引操作

### 普通索引

```sql
-- 创建索引
CREATE INDEX idx_email ON users(email);

-- 创建唯一索引
CREATE UNIQUE INDEX idx_email_unique ON users(email);

-- 联合索引
CREATE INDEX idx_name_age ON users(name, age);

-- 查看索引
SHOW INDEX FROM users;

-- 删除索引
DROP INDEX idx_email ON users;
```

### 使用 ALTER TABLE 创建索引

```sql
ALTER TABLE users ADD INDEX idx_name (name);
ALTER TABLE users ADD UNIQUE INDEX idx_email (email);
ALTER TABLE users ADD FULLTEXT INDEX idx_content (content);  -- 全文索引
```

## 约束操作

```sql
-- 添加主键
ALTER TABLE users ADD PRIMARY KEY (id);

-- 添加唯一约束
ALTER TABLE users ADD UNIQUE KEY uk_email (email);

-- 添加外键约束
ALTER TABLE orders ADD CONSTRAINT fk_user
    FOREIGN KEY (user_id) REFERENCES users(id)
    ON DELETE CASCADE ON UPDATE CASCADE;

-- 删除外键
ALTER TABLE orders DROP FOREIGN KEY fk_user;
```

## 截断与删除表

```sql
-- 清空表数据（不可回滚，自增 ID 重置）
TRUNCATE TABLE temp_logs;

-- 删除表结构和数据
DROP TABLE temp_logs;
DROP TABLE IF EXISTS temp_logs;
```

| 操作 | 速度 | 回滚 | 自增值 | DDL/DML |
|------|------|------|--------|---------|
| `DELETE FROM t` | 慢（逐行删除）| 可回滚 | 不变 | DML |
| `TRUNCATE t` | 快 | 不可回滚 | 重置 | DDL |
| `DROP TABLE t` | 快 | 不可回滚 | — | DDL |

## 常用信息查询

```sql
-- 查看所有表
SHOW TABLES;
SHOW TABLES FROM mysql;

-- 查看表结构
DESC users;
SHOW COLUMNS FROM users;

-- 查看建表语句
SHOW CREATE TABLE users;

-- 查看表大小
SELECT
    table_name,
    ROUND((data_length + index_length) / 1024 / 1024, 2) AS size_mb
FROM information_schema.tables
WHERE table_schema = 'shop' AND table_name = 'users';

-- 查看所有表大小
SELECT
    table_name,
    ROUND((data_length + index_length) / 1024 / 1024, 2) AS size_mb
FROM information_schema.tables
WHERE table_schema = 'shop'
ORDER BY size_mb DESC;
```

## 最佳实践

### 1. 始终指定字符集

```sql
CREATE DATABASE db CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE TABLE t (...) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2. 表字段顺序

```sql
CREATE TABLE good_example (
    id          BIGINT UNSIGNED AUTO_INCREMENT,   -- 主键
    user_id     INT UNSIGNED NOT NULL,             -- 外键
    name        VARCHAR(50) NOT NULL,              -- 业务字段
    status      TINYINT NOT NULL DEFAULT 0,        -- 状态
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP,-- 时间字段放最后
    updated_at  DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
    PRIMARY KEY (id)
);
```

### 3. 字段注释

每条字段都加注释，方便团队协作：

```sql
CREATE TABLE products (
    id          INT UNSIGNED AUTO_INCREMENT PRIMARY KEY COMMENT '商品ID',
    name        VARCHAR(200) NOT NULL COMMENT '商品名称',
    price       DECIMAL(10,2) NOT NULL COMMENT '单价（元）',
    stock       INT NOT NULL DEFAULT 0 COMMENT '库存数量',
    status      TINYINT NOT NULL DEFAULT 1 COMMENT '状态:1上架0下架',
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间'
) COMMENT='商品表';
```

### 4. 避免保留字

不要用 MySQL 保留字做表名或列名。确需要使用请加反引号：

```sql
-- ❌ 不推荐
CREATE TABLE order (...)  -- order 是保留字

-- ✅ 正确
CREATE TABLE `order` (...)

-- ✅ 更推荐
CREATE TABLE orders (...)
```
