## 一、用户管理

### 查看用户

```sql
SELECT User, Host, plugin, authentication_string
FROM mysql.user;

-- 格式化查看
SELECT
    User,
    Host,
    account_locked,
    password_expired,
    password_last_changed
FROM mysql.user;
```

### 创建用户

```sql
-- 基本创建
CREATE USER 'app_user'@'localhost' IDENTIFIED BY 'secure_password_123';

-- 允许从任意 IP 连接
CREATE USER 'app_user'@'%' IDENTIFIED BY 'secure_password_123';

-- 限定网段
CREATE USER 'admin'@'192.168.1.%' IDENTIFIED BY 'another_password';

-- 创建后立即修改密码
ALTER USER 'app_user'@'localhost' IDENTIFIED BY 'new_password';
```

### 删除用户

```sql
DROP USER 'old_user'@'localhost';
DROP USER IF EXISTS 'old_user'@'localhost';
```

## 二、权限体系

### 权限层级

```
全局权限（*.*）
  └── 数据库权限（db.*）
        └── 表权限（db.table）
              └── 列权限（db.table.col）
```

### 授予权限

```sql
-- 给用户赋予数据库的所有权限（不包括 grant 权限）
GRANT ALL PRIVILEGES ON shop.* TO 'app_user'@'localhost';

-- 只读权限
GRANT SELECT ON shop.* TO 'readonly_user'@'%';

-- 精确权限（常用组合）
GRANT SELECT, INSERT, UPDATE, DELETE ON shop.* TO 'app_user'@'%';

-- 创建和修改表的权限（仅限 DBA 使用）
GRANT CREATE, ALTER, DROP, INDEX ON shop.* TO 'dba_user'@'localhost';

-- 存储过程权限
GRANT EXECUTE ON PROCEDURE shop.get_user_orders TO 'app_user'@'%';

-- 按列授权（特殊场景）
GRANT SELECT (id, name, email) ON shop.users TO 'analyst'@'%';

-- 一定要最后执行
FLUSH PRIVILEGES;
```

### 撤销权限

```sql
-- 撤销所有写入权限
REVOKE INSERT, UPDATE, DELETE ON shop.* FROM 'app_user'@'%';

-- 撤销所有权限
REVOKE ALL PRIVILEGES ON shop.* FROM 'user'@'%';

-- 回收后刷新
FLUSH PRIVILEGES;
```

### 查看权限

```sql
-- 查看当前用户权限
SHOW GRANTS;

-- 查看指定用户权限
SHOW GRANTS FOR 'app_user'@'localhost';

-- 查看当前用户的全局权限
SELECT * FROM mysql.user WHERE user = 'root'\G
```

### 常用权限组合

| 角色类型 | 权限 | 说明 |
|---------|------|------|
| 只读账号 | `SELECT` | 供 BI 工具、数据分析使用 |
| 应用账号 | `SELECT, INSERT, UPDATE, DELETE` | 应用程序连接 |
| DBA 账号 | `ALL PRIVILEGES` | 数据库管理员，加 `WITH GRANT OPTION` |
| 备份账号 | `SELECT, LOCK TABLES, RELOAD, REPLICATION CLIENT` | 备份专用 |
| 主从账号 | `REPLICATION SLAVE, REPLICATION CLIENT` | 从库连接 |

```sql
-- 应用账号示例
CREATE USER 'app'@'192.168.10.%' IDENTIFIED BY 'app_password123!';
GRANT SELECT, INSERT, UPDATE, DELETE ON shop.* TO 'app'@'192.168.10.%';
FLUSH PRIVILEGES;

-- 只读账号示例
CREATE USER 'readonly'@'%' IDENTIFIED BY 'readonly_pass!';
GRANT SELECT ON shop.* TO 'readonly'@'%';
FLUSH PRIVILEGES;
```

## 三、密码策略

### 查看当前策略

```sql
SHOW VARIABLES LIKE 'validate_password%';
```

### 设置密码策略（需要 validate_password 插件）

```sql
-- 启用密码校验插件
INSTALL COMPONENT 'file://component_validate_password';

-- 设置密码策略等级（0=低, 1=中, 2=强）
SET GLOBAL validate_password.policy = MEDIUM;

-- 密码最小长度
SET GLOBAL validate_password.length = 12;

-- 要求包含大写字母、小写字母、数字、特殊字符
SET GLOBAL validate_password.mixed_case_count = 1;
SET GLOBAL validate_password.number_count = 1;
SET GLOBAL validate_password.special_char_count = 1;
```

### 密码过期策略

```sql
-- 设置用户密码 90 天过期
ALTER USER 'app_user'@'localhost' PASSWORD EXPIRE INTERVAL 90 DAY;

-- 密码永不过期（不推荐）
ALTER USER 'app_user'@'localhost' PASSWORD EXPIRE NEVER;

-- 强制用户在下次登录时修改密码
ALTER USER 'app_user'@'localhost' PASSWORD EXPIRE;

-- 设置全局密码过期策略（在 my.cnf 中）
-- default_password_lifetime = 90
```

## 四、连接安全

### 限制连接

```sql
-- 限制用户的最大连接数
ALTER USER 'app_user'@'%' WITH MAX_USER_CONNECTIONS 50;

-- 全局最大连接数
-- 在 my.cnf 中设置：
-- max_connections = 500
```

### 绑定地址

```ini
# my.cnf
[mysqld]
# 只监听本地连接
bind-address = 127.0.0.1

# 监听指定内网 IP
bind-address = 192.168.1.100

# 监听所有（不推荐）
# bind-address = 0.0.0.0
```

## 五、SSL/TLS 加密连接

### 配置 MySQL SSL

```ini
# my.cnf
[mysqld]
ssl-ca = /etc/mysql/ssl/ca.pem
ssl-cert = /etc/mysql/ssl/server-cert.pem
ssl-key = /etc/mysql/ssl/server-key.pem

require_secure_transport = ON  # 强制使用 SSL
```

### 创建必须使用 SSL 连接的用户

```sql
CREATE USER 'secure_user'@'%' IDENTIFIED BY 'password'
REQUIRE SSL;

-- 更严格：要求 X509 证书
CREATE USER 'cert_user'@'%' IDENTIFIED BY 'password'
REQUIRE X509;
```

### 验证连接是否使用 SSL

```sql
-- 连接后查看
SHOW STATUS LIKE 'Ssl_cipher';
-- 有值表示当前连接使用了 SSL 加密
```

## 六、审计与日志

### 审计谁在连接

```sql
-- 查看当前所有连接
SHOW PROCESSLIST;
SHOW FULL PROCESSLIST;

-- 查看连接来源
SELECT
    user,
    host,
    db,
    command,
    time,
    state,
    info
FROM information_schema.PROCESSLIST;
```

### 查询日志

```sql
-- 开启查询日志（生产环境小心！会写大量日志）
SET GLOBAL general_log = ON;
SET GLOBAL general_log_file = '/var/log/mysql/query.log';

-- 只查看近期查询
SELECT * FROM mysql.general_log
WHERE event_time > NOW() - INTERVAL 5 MINUTE;
```

**生产环境建议**：用 Performance Schema 代替 general log，对性能影响更小：

```sql
SELECT *
FROM performance_schema.events_statements_history
WHERE thread_id = (SELECT thread_id FROM performance_schema.threads
                   WHERE processlist_id = CONNECTION_ID());
```

### 审计插件

MySQL Enterprise 提供审计插件，或者使用第三方的 audit 插件。

```ini
# my.cnf（需要安装 audit 插件）
[mysqld]
plugin-load-add = audit_log.so
audit_log_policy = LOGINS  # 只记录登录事件
# audit_log_policy = ALL   # 记录所有操作
```

## 七、SQL 注入防护

> 本系列第 13 篇会详细讲解 SQL 注入，这里只提数据库层面的安全配置。

### 禁用危险功能

```sql
-- 禁用 LOAD DATA LOCAL INFILE（防止读取服务器文件）
-- 需要在 my.cnf 中设置：
-- local-infile = 0

-- 禁用文件权限（应用账号不授 FILE 权限）
-- FILE 权限允许使用 SELECT ... INTO OUTFILE 写文件
```

### 最小权限的检查清单

```
数据库用户权限检查清单：
□ 应用账号只有 SELECT, INSERT, UPDATE, DELETE
□ 不授予 DDL 权限（CREATE, ALTER, DROP）
□ 不授予 FILE 权限
□ 不授予 SUPER 权限
□ 不授予 GRANT OPTION
□ 限制连接来源 IP
□ 限制最大连接数
□ 定期轮换密码
```

## 八、安全最佳实践汇总

### my.cnf 安全配置

```ini
[mysqld]
# 端口和绑定
port = 3306
bind-address = 192.168.1.100

# 禁用 local-infile
local-infile = 0

# 跳过符号链接（防止 link 到敏感文件）
skip_symbolic_links = yes

# 日志
log_error = /var/log/mysql/error.log
slow_query_log = ON
long_query_time = 2

# 密码策略
default_password_lifetime = 90
password_history = 10           # 不能重复使用最近 10 个密码
password_reuse_interval = 365   # 365 天内不能重复使用密码

# 连接安全
max_connect_errors = 100        # 超过 100 次错误连接则阻塞 IP
skip_name_resolve               # 不解析主机名（减少 DNS 风险）

# 如果启用 SSL
# require_secure_transport = ON
```

### 定期安全任务

```bash
#!/bin/bash
# 定期安全巡检脚本

echo "=== MySQL 安全检查 $(date) ==="

# 1. 检查有没有无密码用户
mysql -u root -p -e "
SELECT User, Host FROM mysql.user
WHERE authentication_string = '' OR authentication_string IS NULL;
"

# 2. 检查过期密码
mysql -u root -p -e "
SELECT User, Host, password_expired FROM mysql.user
WHERE password_expired = 'Y';
"

# 3. 检查未使用 SSL 的用户
mysql -u root -p -e "
SELECT User, Host, ssl_type FROM mysql.user
WHERE ssl_type = '';
"

# 4. 检查是否有用户被锁
mysql -u root -p -e "
SELECT User, Host, account_locked FROM mysql.user
WHERE account_locked = 'Y';
"

echo "=== 检查完成 ==="
```
